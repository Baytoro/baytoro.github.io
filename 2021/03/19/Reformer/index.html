Paper

Reformer 是高效 Transformer 早期路线里很有代表性的一篇。它同时处理两个瓶颈：attention 的 复杂度，以及深层网络保存 activation 的内存。对应方法是 LSH attention 和 reversible residual layers。

LSH Attention

普通 attention 需要所有 query-key pair。Reformer 的观察是：softmax attention 里真正重要的是相似 query/key。于是用 locality-sensitive hashing 把相似 token 分到同一 bucket，只在 bucket 内做 attention。

如果 hash 后每个 bucket 大小近似固定，复杂度可以从 降到接近 。代价是近似：hash collision 决定哪些 token 能互相看见，不能保证完全等价于 full attention。

Takeaway

Reformer 的工程意义在于把长序列问题拆成两类优化：

  • attention pattern 近似，减少 token pair；
  • activation checkpoint/recompute，减少训练内存。

后来的 FlashAttention 选择了另一条路：不近似 attention，而是通过 IO-aware tiling 降低 HBM 读写。对比这两条路线很重要：Reformer 牺牲精确性换复杂度，FlashAttention 保持精确但优化 kernel 组织。

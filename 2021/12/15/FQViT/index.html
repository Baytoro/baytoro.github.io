FQ-ViT: Post-Training Quantization for Fully Quantized Vision Transformer

H.J. Chen
  2021-12-15 2021-12-15 Created  
  • Work hard 
  • >
  • PaperReading 
 
  • Quantization 
  • | ViT

Lin Y, Zhang T, Sun P, Li Z, Zhou S. FQ-ViT: Post-Training Quantization for Fully Quantized Vision Transformer. arXiv 2021.

Paper

FQ-ViT is a post-training quantization paper about a stricter question than normal “W8A8 works” claims:

Can the whole Vision Transformer graph be quantized, including LayerNorm and Softmax?

That word “fully” matters. If Linear/MatMul layers are INT8 but LayerNorm and Softmax remain floating point, the model still needs float kernels, dequantize/requantize boundaries, and extra memory movement. FQ-ViT focuses on these hard operators instead of only the easy GEMM-heavy parts.

The paper proposes two components:

  • Power-of-Two Factor (PTF) for LayerNorm input quantization;
  • Log-Int-Softmax (LIS) for integer-only Softmax and low-bit attention maps.

All figures and tables below are cropped from the original arXiv PDF.

Motivation

Vision Transformer quantization is not just CNN quantization with bigger matrices. A ViT block contains:

  • Q/K/V projections;
  • attention-score MatMul;
  • Softmax over attention scores;
  • attention-value MatMul;
  • output projection;
  • MLP layers;
  • LayerNorm;
  • residual additions.

Linear layers are the easy part. LayerNorm and Softmax are the deployment problem.

Figure 1 compares four settings:

  • full precision;
  • not fully quantized, where LayerNorm and Softmax remain floating point;
  • vanilla fully quantized with standard MinMax treatment;
  • FQ-ViT’s fully quantized method.

The collapse of vanilla fully quantization is the key observation. Some models tolerate it, but large ViT/Swin models can lose most of their accuracy when LayerNorm and Softmax are naively quantized. FQ-ViT tries to make the hard operators quantization-friendly.

What “Fully Quantized” Means

For FQ-ViT, fully quantized means the graph should avoid floating-point islands in the critical path.

Operator Normal PTQ difficulty FQ-ViT treatment
Conv / Linear relatively easy MinMax uniform quantization
MatMul relatively easy integer MatMul
LayerNorm hard Power-of-Two Factor
Softmax hard Log-Int-Softmax
Attention map sensitive log2-style low-bit representation

This is the same engineering pressure that appears in I-BERT for language models: nonlinear and normalization operators decide whether “integer inference” is real or cosmetic.

LayerNorm Problem

LayerNorm cannot usually be folded into the previous layer in the same way BatchNorm can be folded into a convolution. It depends on the current input’s mean and variance, so it remains an active operator at inference time.

FQ-ViT observes that LayerNorm inputs in ViTs have strong inter-channel variation.

The left plot compares channel-wise ranges for ResNet and Transformer models. The right plot shows channel-wise minimum and maximum values for Swin-B. The transformer activations have much stronger inter-channel variation than the CNN comparison.

This breaks simple layer-wise MinMax quantization. A single scale must cover extreme channels, so normal channels receive poor resolution. Channel-wise quantization could help accuracy, but it increases hardware complexity because every channel needs separate quantization parameters.

Power-of-Two Factor

PTF is a compromise between layer-wise and channel-wise quantization.

The idea is:

  1. Keep a layer-wise quantization scale.
  2. Give each channel a power-of-two factor.
  3. Implement channel adjustment with bit shifts rather than expensive arbitrary scaling.

The paper’s default hyperparameter is K = 3, meaning the per-channel factor is selected from a small set of powers of two. This gives channels enough scale flexibility without turning LayerNorm into a fully channel-wise floating-point operation.

At inference, PTF lets the quantized LayerNorm path shift activations to reduce inter-channel range mismatch, compute approximate statistics, and keep the output quantized.

The hyperparameter curve shows that accuracy is mostly saturated when K = 3, which is why the paper uses it as the default.

Softmax Problem

Attention maps have a very different distribution from normal activations. Most probabilities are tiny, and a few entries dominate. Uniform quantization wastes too much resolution on large values and gives too little resolution to small positive values.

The figure compares 4-bit bins for uniform quantization and log2 quantization on a ViT-L attention map. Log-style quantization allocates more bins to small values, which is the part of the distribution where attention probabilities are dense.

Softmax is also a graph-level deployment issue. If Softmax stays in full precision, attention inference must dequantize before Softmax and requantize afterward.

The left side keeps full-precision Softmax in the attention path. The right side uses Log-Int-Softmax. Instead of producing a normal floating-point attention matrix, LIS keeps the Softmax-related path in integer form and uses bit shifts when multiplying attention by values.

This is why FQ-ViT can report attention maps at 4-bit in some settings. The method is not only compressing weights; it is changing how the Softmax path is represented.

Log-Int-Softmax

The paper builds LIS on integer-only exponential ideas from I-BERT. The high-level route is:

  1. subtract the maximum score before Softmax for numerical stability;
  2. approximate exponential in integer arithmetic;
  3. use a log2 representation for the reverse Softmax output;
  4. combine attention and values with bit shifts instead of floating-point multiply.

The algorithms are useful because they make “fully quantized” concrete. The difficult part is not storing an attention map in fewer bits. The difficult part is computing and consuming that map without falling back to float.

The appendix compares normal exponential with the integer-only approximation. The approximation is designed to be good enough for quantized Softmax while remaining integer-friendly.

ImageNet Results

Representative ImageNet top-1 results:

Model Full precision FQ-ViT 8/8/8 FQ-ViT 8/8/4
DeiT-T 72.21 71.61 71.07
DeiT-S 79.85 79.17 78.40
DeiT-B 81.85 81.20 80.85
ViT-B 84.53 83.31 82.68
ViT-L 85.81 85.03 84.89
Swin-T 81.35 80.51 80.04
Swin-S 83.20 82.71 82.47
Swin-B 83.60 82.97 82.38

Here W/A/Attn = 8/8/8 means weights, activations, and attention maps are all 8-bit. 8/8/4 keeps weights and activations at 8-bit but uses 4-bit attention maps.

The important comparison is not only against full precision. It is against methods that do not fully quantize LayerNorm and Softmax. Those methods can have good accuracy, but the graph still contains floating-point islands.

COCO Detection

FQ-ViT also evaluates Swin-based detectors on COCO:

Model Full precision FQ-ViT 8/8/8 FQ-ViT 8/8/4
Mask R-CNN w/ Swin-S 48.5 47.8 47.2
Cascade Mask R-CNN w/ Swin-S 52.0 51.4 50.8

The paper reports that current fully quantized baselines perform poorly on these detectors, while FQ-ViT keeps the degradation small. The Cascade Mask R-CNN result at 50.8 mAP with 4-bit attention is one of the headline numbers from the abstract.

Ablation

The ViT-B ablation isolates PTF and LIS:

Setting Accuracy
full precision 84.53
8-bit baseline, no PTF/LIS 23.64
8-bit baseline + PTF 83.31
4-bit attention baseline + PTF, no LIS 7.96
4-bit attention baseline + PTF + LIS 82.68

This is the cleanest evidence in the paper. PTF is the critical fix for full 8-bit quantization. LIS is the critical fix when attention maps are compressed to 4-bit.

The attention-map visualization makes the same point qualitatively. Uniform low-bit attention loses structure as bit-width drops. Log-Int-Softmax preserves the attention pattern much better.

Channel Variation Appendix

The appendix plots channel-wise minimum and maximum values across several ResNet and Transformer models. The ViT/Swin plots show the outlier-like channel behavior that motivates PTF. This is a useful diagnostic for any reproduction: before designing a quantizer, look at the tensor distribution that the quantizer must represent.

Reproduction Notes

For a serious reproduction, I would report operator coverage explicitly:

Path What to verify
Q/K/V projections integer Linear/MatMul kernels
attention score integer MatMul and scale handling
Softmax LIS path, no hidden float fallback
attention times V integer or bitshift-compatible path
LayerNorm PTF path, no float LayerNorm fallback
residual add compatible scales or explicit requantization
MLP integer Linear/GELU handling or documented fallback

Accuracy alone is not enough. A model can be accurate with quantized weights but still fail the purpose of this paper if LayerNorm and Softmax silently run in float.

I would also log:

  • channel-wise ranges before LayerNorm;
  • the selected PTF factors per layer;
  • attention-map histograms before and after LIS;
  • top-k attention overlap between full precision and quantized models;
  • end-to-end operator dtype coverage in the actual backend.

Limitations

FQ-ViT is post-training quantization, so it avoids retraining cost but depends heavily on calibration quality. The paper samples 1000 training images for calibration in its experiments. Bad calibration can still break low-bit attention or LayerNorm statistics.

The deployment benefit also depends on backend support. If the runtime cannot execute PTF LayerNorm or LIS Softmax efficiently, the method may evaluate correctly but not deliver a real integer-only speedup.

Finally, the paper focuses on ViT/Swin-style vision transformers. The ideas are relevant to language models, but sequence length, causal masking, KV cache behavior, and activation outliers make LLM deployment a different problem.

Takeaway

FQ-ViT is valuable because it treats quantization as an operator-coverage problem. Linear layers are not enough. LayerNorm and Softmax decide whether a Vision Transformer can actually run as a fully quantized graph.

The two main ideas are easy to remember:

  • PTF uses power-of-two channel factors to make LayerNorm input quantization tolerate inter-channel variation.
  • LIS uses a log-domain integer-friendly Softmax path so attention maps can be quantized, even to 4-bit in the paper’s experiments.

When reading later quantization papers, I use FQ-ViT as a checklist: show the accuracy table, but also show which operators still run in floating point.

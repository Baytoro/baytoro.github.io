DrNAS: Dirichlet Neural Architecture Search

H.J. Chen
  2021-12-22 2021-12-22 Created  
  • Paper Reading 
 
  • NAS 

Chen, Wang, Cheng, Tang, and Hsieh. DrNAS: Dirichlet Neural Architecture Search. ICLR 2021.

Paper

DrNAS targets the failure mode that makes DARTS-style NAS hard to trust: the search can collapse early into shallow or skip-heavy architectures, and the final cell can be very sensitive to seed, search space, and training length.

The paper’s idea is to treat architecture mixing weights as random variables on the probability simplex. Instead of learning one deterministic softmax vector, DrNAS samples operation weights from a Dirichlet distribution and regularizes that distribution around a stable anchor.

From Softmax Weights To Dirichlet Samples

DARTS relaxes a discrete edge choice into a deterministic mixture:

DrNAS keeps the mixture view but makes the mixing vector stochastic:

The concentration parameter beta controls how samples behave. A broad distribution keeps exploration alive; a concentrated distribution moves toward confident operation selection. The final discrete architecture is derived from the Dirichlet mean.

Figure 1 shows the range of accuracies from sampled architectures on NAS-Bench-201. The solid line is the architecture selected by the Dirichlet mean. This is a useful diagnostic: the method is not only trying to find one good point, but to keep the architecture distribution well behaved during search.

Anchor Regularization

A raw Dirichlet search can still become unstable because the variance of the distribution is hard to control. DrNAS adds an anchor regularizer that keeps the learned concentration parameter near a symmetric Dirichlet anchor:

The paper also connects this regularization to the Hessian of the validation loss with respect to the architecture parameters. The practical reading is simple: DrNAS tries to avoid the sharp, unstable search trajectory that often appears in DARTS.

The gradients still need to pass through samples from a Dirichlet distribution. Since the ordinary reparameterization trick does not directly apply, the paper uses pathwise derivative estimators for Dirichlet samples.

Progressive Learning

DrNAS also introduces a progressive architecture learning scheme:

  • start with a cheaper partial-channel search;
  • gradually increase the channel fraction through network transformation;
  • progressively prune weak candidate operations;
  • keep memory usage controlled while searching on larger tasks.

This is important because a probabilistic search method is not useful if it only works on a tiny proxy cell. The progressive schedule is the bridge from NAS-Bench/CIFAR experiments to ImageNet-scale search.

The discovered normal and reduction cells still look like the usual cell-based NAS artifacts. DrNAS is not replacing the DARTS search space. It is changing the optimization dynamics inside that search space.

CIFAR-10 Results

On CIFAR-10, the paper reports:

Method Test error Params Search cost
DARTS second-order 2.76 +/- 0.09% 3.3M 1.0 GPU day
PC-DARTS 2.57 +/- 0.07% 3.6M 0.1 GPU day
DrNAS without progressive learning 2.54 +/- 0.03% 4.0M 0.4 GPU day
DrNAS 2.46 +/- 0.03% 4.1M 0.6 GPU day

The interesting part is not just the 2.46% number. DrNAS improves while staying in the gradient-based NAS family, which makes the result more comparable to DARTS, PC-DARTS, and SDARTS than to very large RL/evolution searches.

ImageNet Mobile Setting

On ImageNet mobile classification, DrNAS reports 23.7% top-1 error and 7.1% top-5 error with 5.7M parameters and 4.6 GPU days of search. The non-progressive ImageNet version reports 24.2% / 7.3% with 5.2M parameters.

That improvement is small but meaningful in this comparison group. It supports the claim that progressive learning is not only a memory trick; it also improves the final searched architecture.

NAS-Bench-201

NAS-Bench-201 is useful because it reduces the ambiguity of retraining and random search-space quirks. In this table, DrNAS reaches strong accuracy on CIFAR-10, CIFAR-100, and ImageNet16-120. The reported CIFAR-10 test accuracy is 94.36%, with validation accuracy 91.55%.

I usually trust this kind of benchmark more for stability claims than for absolute model quality. It tests whether the search method consistently selects good architectures inside a controlled finite space.

Regularizer Sensitivity

The anchor regularizer table is a good detail. Without the regularizer, the reported NAS-Bench-201 CIFAR-10 accuracy is 93.78%. A range of regularizer strengths reaches 94.36%, while overly large values fall back to 93.76%.

This suggests the method is not tuned to one exact lambda, but the regularizer is still doing real work. Too little regularization leaves the distribution unstable; too much prevents useful concentration.

Takeaway

DrNAS should be read as a stabilization paper for differentiable NAS:

  • DARTS uses deterministic softmax architecture weights.
  • DrNAS samples architecture weights from a Dirichlet distribution.
  • The anchor regularizer controls the architecture distribution and helps avoid sharp search dynamics.
  • Progressive learning makes the method practical beyond tiny proxy settings.

The limitation is that the search space is still the familiar cell-based NAS space. DrNAS improves how the architecture parameters are optimized; it does not remove the assumptions baked into the candidate operations and cell topology. That is still useful, because instability is one of the main reasons DARTS-style results are hard to reproduce.

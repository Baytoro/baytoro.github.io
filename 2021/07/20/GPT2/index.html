Language Models are Unsupervised Multitask Learners

Paper

GPT-2 的标题很直接：语言模型本身能不能通过自然语言上下文学习任务？它没有引入新架构，仍然是 decoder-only Transformer；变化在数据和规模。WebText 的构造、byte-level BPE、模型扩大到 1.5B 参数，使 zero-shot evaluation 第一次变成主角。

Motivation

GPT-1 还依赖 supervised fine-tuning。GPT-2 试图把任务描述、示例、输入都放进自然语言上下文，让模型用下一个 token 预测完成任务。论文里的翻译、摘要、问答、阅读理解都不是专门训练出来的 head，而是语言建模目标的副产品。

图中最重要的趋势是：随着模型从 117M 到 1.5B，多个任务的 zero-shot 性能稳定上升。它并不总是 SOTA，但曲线说明“更大的通用 LM + 自然语言任务格式”可以产生跨任务迁移。

Dataset and Tokenization

WebText 从 Reddit 高 karma outbound links 抽取网页，去掉 Wikipedia，得到约 40GB 文本。这个选择有两个含义：第一，数据来自更接近真实网络文本的分布；第二，任务示例可能自然出现在文本里，例如翻译对、问答格式、摘要格式。

GPT-2 使用 byte-level BPE，避免传统 tokenization 的 OOV 问题。语言模型目标仍是：

但输入分布更杂，模型更大，训练出的表示也更接近“从上下文里识别任务”。

Architecture

GPT-2 延续 GPT-1 的 decoder-only Transformer，但做了工程调整：LayerNorm 移到每个 sub-block 输入处，残差路径初始化按层数缩放，context length 扩到 1024。最大模型 1.5B 参数，48 层，1600 hidden size，25 heads。

随着参数变大，WebText train/test perplexity 同时下降，test 曲线没有明显反弹。这说明当时模型还没有把数据吃满，扩大模型仍然有效。

Results and Limits

GPT-2 在 LAMBADA 上提升明显，说明长距离上下文有用；在摘要、翻译、问答上也展示 zero-shot 能力，但离 supervised SOTA 仍有距离。论文最有启发的是失败也很清楚：模型经常抓住任务格式，却缺乏稳定的指令遵循和事实可靠性。

这解释了后续 GPT-3、InstructGPT 的方向：GPT-2 证明了自然语言任务格式可行，但还需要更大规模、更好的 few-shot prompting，以及人类反馈对齐来提高可控性。

Takeaway

GPT-2 的贡献可以总结为：

  • decoder-only LM 可以在没有任务微调时做多任务迁移；
  • 数据质量和任务自然出现的频率会影响 zero-shot；
  • byte-level BPE 和更长 context 支撑开放文本建模；
  • scaling 趋势比单个 benchmark 数字更重要。

从这篇开始，GPT 路线不再只是“预训练后微调”，而是逐渐转向“在上下文中指定任务”。

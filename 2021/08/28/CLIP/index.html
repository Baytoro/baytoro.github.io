CLIP: Learning Transferable Visual Models From Natural Language Supervision

H.J. Chen
  2021-08-28 2021-08-28 Created  
  • Paper Reading 
 
  • AIGC 
  • | Transformer

  • | Multimodal 

Paper / Code

CLIP is the paper that made “classification by text prompt” feel practical at scale. The idea is simple to state: train an image encoder and a text encoder on internet image-text pairs, then use text descriptions as classifiers at test time.

The important shift is the label space. Instead of predicting one fixed set of dataset labels, CLIP learns a shared embedding space where images and natural-language descriptions can be compared directly. That makes zero-shot classification, retrieval, and open-vocabulary use cases much more natural.

Training And Zero-shot Use

Figure cropped from the paper PDF: CLIP pre-trains with paired image-text examples, then builds a zero-shot classifier from label text.

The training batch contains aligned image-text pairs. The image encoder maps images into a normalized embedding, and the text encoder maps captions into the same embedding space. The model computes all image-text similarities in the batch and uses the matching diagonal as positives.

The zero-shot classifier is just the same mechanism reused at inference time:

  1. Convert each class name into a prompt, such as a photo of a {label}.
  2. Encode all class prompts with the text encoder.
  3. Encode the image with the image encoder.
  4. Choose the prompt embedding with the highest similarity.

That means a new label set does not require training a new linear head. It only requires writing label text.

Why Contrastive Learning

Contrastive training is more data efficient than the caption-prediction baselines in this comparison.

The paper compares three objectives on zero-shot ImageNet accuracy as training compute increases. The contrastive bag-of-words variant learns much faster than the caption-prediction alternatives. The result is not only that more data helps. It is that the objective matters.

The core implementation is short:

The paper’s numpy-like pseudocode: normalized image/text embeddings, scaled cosine similarities, and symmetric cross entropy.

The symmetric loss is worth noting. CLIP trains both image-to-text and text-to-image matching. In a batch of N pairs, each image should match its paired text better than the other N - 1 texts, and each text should match its paired image better than the other N - 1 images.

Prompt Engineering

Prompt engineering and prompt ensembling improve zero-shot classification without retraining the image model.

The paper found that bare class names are often a poor interface to the text encoder. A prompt such as a photo of a {label} gives useful context, and task-specific prompts can help even more. For fine-grained datasets, adding the category type matters, for example writing that the label is a pet, food, aircraft, or satellite image.

Prompt ensembling is the same idea repeated with multiple contexts. Encode several prompts per class, average them in embedding space, and use the result as the text classifier. This costs more text-encoder work when building the classifier, but that cost is amortized across many image predictions.

Zero-shot Evaluation

Zero-shot CLIP versus a fully supervised linear probe on ResNet-50 features across 27 datasets.

CLIP’s zero-shot behavior is uneven, which is one of the more useful parts of the paper. It is strong on datasets where natural language names line up well with visual concepts, such as StanfordCars, Country211, Food101, and Kinetics700. It is weaker on some specialized datasets, including EuroSAT, KITTI Distance, PatchCamelyon, GTSRB, and CLEVRCounts.

This is a good reminder: zero-shot does not mean uniformly strong. It means the model can attempt a task through language. Whether that language interface contains enough signal depends on the dataset.

Few-shot Comparison

Zero-shot CLIP is close to a few-shot linear probe on the same feature space in the paper’s aggregate comparison.

One surprising result is that zero-shot CLIP can match the average performance of a 4-shot logistic regression classifier trained on the same feature space. This does not mean zero-shot is always better than few-shot. It means language priors can be strong enough that a prompt-based classifier is competitive with a tiny labeled set.

The paper also points out a practical research direction: combining the zero-shot classifier as a prior with few-shot learning should be better than treating the two as unrelated methods.

Linear Probe And Model Scale

CLIP features are competitive with strong supervised and self-supervised vision models under linear probing.

The linear-probe results separate two questions:

  • Are the learned visual features good?
  • Is the text-generated zero-shot classifier good?

CLIP is strong on both, but they are not identical. A feature space can be useful while the zero-shot text interface still loses points because the prompt or label set is imperfect. This distinction is important when debugging CLIP-style systems: sometimes the problem is representation quality, and sometimes the problem is the text classifier specification.

Robustness Under Distribution Shift

Zero-shot CLIP reduces the ImageNet robustness gap on several natural distribution shifts.

The robustness result is one of the paper’s most interesting claims. Standard ImageNet-trained models can do well on ImageNet validation but drop sharply under natural distribution shifts. Zero-shot CLIP narrows that gap, likely because it is not tuned directly to the ImageNet training distribution and because its class interface can be adapted with text.

The right side of the figure uses banana examples to make the shift concrete: ImageNet, ImageNetV2, ImageNet-R, ObjectNet, ImageNet Sketch, and ImageNet-A can contain visually different versions of the same semantic class. CLIP handles several of these shifts better than a similarly accurate ImageNet model.

Reading Notes

CLIP’s influence comes from making the text interface a first-class part of visual recognition:

  • Labels become natural-language descriptions.
  • Adding a class can be done by adding text.
  • Retrieval and classification share the same embedding space.
  • Prompt design becomes part of model evaluation.

The limitations are also clear. CLIP learns from noisy web image-text pairs, so biases and spurious correlations matter. It is not a full visual reasoning system. It can fail on fine-grained spatial tasks, abstract synthetic tasks, medical/satellite-style domains, and settings where the class names do not describe the visual decision well.

The practical takeaway for me: CLIP is not “zero-shot magic.” It is a very strong interface between language and visual representations. The quality of that interface depends on pre-training scale, objective design, prompt wording, and whether the target task can actually be expressed through text.

Improving Language Understanding by Generative Pre-Training

Paper

GPT-1 的价值不是模型有多大，而是它把一个很干净的流程跑通了：先在大规模无标注文本上做生成式语言模型预训练，再用少量任务格式转换把分类、蕴含、问答、多选题都塞进同一个 Transformer decoder 里微调。

Motivation

当时 NLP 任务很多，但高质量标注数据少。ELMo 这类方法已经证明无监督表示有用，但常见做法是把预训练表示作为 feature 接到任务模型上。GPT-1 更接近今天的范式：预训练模型本身就是主干，下游任务只需要轻量输出层和输入格式转换。

这张图右半部分很关键。GPT-1 没有为每个任务重写架构，而是把不同任务统一成 token 序列：分类任务直接 [start] text [extract]，蕴含任务拼接 premise/hypothesis，similarity 任务对两个顺序分别编码，多选题对每个 answer candidate 分别打分。

Layer Transfer

论文做了一个很有用的消融：迁移多少层会影响下游表现。结果显示 embedding 有帮助，但每多迁移一层 Transformer block，MultiNLI 和 RACE 继续提升。这说明预训练学到的不是只在底层的词法特征，高层也包含对下游任务可用的组合能力。

另一个曲线说明预训练步数越多，下游任务整体越好。这里还不是后来的 scaling law，但已经能看到“同一个目标 + 更多文本 + 更大 Transformer”这条路线的轮廓。

Results

GPT-1 在 GLUE、RACE、Story Cloze 等任务上取得明显提升，尤其是自然语言推理和问答。需要注意的是，它仍然是“预训练 + 监督微调”，不是 GPT-2/GPT-3 那种强调 zero-shot/few-shot prompting 的设定。

更重要的是任务接口：通过 delimiter token 和序列拼接，把结构化任务转为语言模型可以处理的序列。这一步后来在 instruction tuning、prompting、text-to-text 里被不断放大。

Takeaway

GPT-1 是 decoder-only LLM 路线的桥：

  • Transformer decoder 作为统一主干；
  • left-to-right LM 作为可扩展预训练目标；
  • 下游任务通过输入改写和少量输出层适配；
  • 微调时继续保留 LM loss 来稳定迁移。

它还没有展示大模型涌现能力，但已经把“生成式预训练是通用初始化”这件事讲清楚了。

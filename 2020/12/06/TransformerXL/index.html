Transformer-XL: Attentive Language Models Beyond a Fixed-Length Context

H.J. Chen
  2020-12-06 2020-12-06 Created  
  • Paper Reading 
 
  • LLM 
  • | AIGC 
  • | Transformer 

Paper

Transformer-XL 解决的是一个后来一直存在的问题：语言模型训练时通常把长文本切成固定长度 segment，普通 Transformer 只能在 segment 内建模。切段边界会造成上下文断裂，推理时也只能重复计算滑动窗口。Transformer-XL 的答案是缓存上一段 hidden states，并用相对位置编码保持位置一致性。

Segment-level Recurrence

普通 Transformer 在第 段只看 ，上一段 的表示被丢掉。Transformer-XL 在第 层把上一段同层 hidden states 缓存为 memory：

$$
\tilde{h}^{n-1}{\tau}=[\operatorname{SG}(h^{n-1}{\tau-1}) \circ h^{n-1}_{\tau}]
$$

其中 表示 stop-gradient，训练时不反传到上一段。当前段第 层 attention 的 key/value 来自这个拼接后的序列，query 仍来自当前段。

这样做有两个收益：训练时上下文长度从 segment length 扩到 segment + memory；推理时不需要每次重新计算历史窗口的 hidden states，可以像 RNN 一样复用状态。

Relative Positional Encoding

只缓存 hidden states 还不够。如果使用绝对位置编码，上一段 token 在上一段里有自己的绝对位置，拼到当前段时位置语义会错。Transformer-XL 把 attention logit 拆成内容项和相对位置项：

前两项分别是 content-content 与 content-position，后两项是全局 bias。关键是 依赖相对距离，而不是绝对 index。这样 memory 复用时，历史 token 相对当前 token 的距离仍然可定义。

Results

论文在 WikiText-103、enwik8、text8 等语言建模数据集上显著超过当时强 baseline。更值得看的是有效上下文分析。

曲线显示 Transformer-XL 可以从更长上下文中持续获益，而没有 recurrence 的普通 Transformer 很快退化。这说明它不是只靠参数量提高 PPL，而是真的让模型利用了跨 segment 信息。

Takeaway

Transformer-XL 是长上下文路线里的早期关键节点：

  • recurrence 不是回到 RNN，而是复用 Transformer hidden states；
  • stop-gradient 让训练成本可控；
  • relative position 解决缓存状态的位置错位；
  • 推理时缓存历史层输出，减少重复计算。

它后面影响了 XLNet，也预示了后来的 KV cache、relative position、长上下文 attention 优化。缺点也明显：缓存长度仍然有限，attention 复杂度仍随可见上下文增长，不能从根上解决 。

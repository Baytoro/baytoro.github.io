XLNet: Generalized Autoregressive Pretraining for Language Understanding

H.J. Chen
  2020-03-12 2020-03-12 Created  
  • Paper Reading 
 
  • AIGC 
  • | Transformer 
  • | NLP 

Paper

XLNet 是 BERT 之后一个很有代表性的目标函数改造。它的批评点是：BERT 的 MLM 会引入 [MASK] 预训练/微调不一致，并且被 mask 的 token 之间条件独立。XLNet 想保留 autoregressive likelihood 的严谨性，同时通过排列分解顺序让每个位置看到双向上下文。

Permutation LM

XLNet 最大化所有 factorization order 的期望：

$$
\max_\theta \mathbb{E}{z\sim \mathcal{Z}T}\left[\sum{t=1}^{T}\log p_\theta(x{z_t}\mid x_{z_{<t}})\right]
$$

这里 是位置排列。注意输入序列本身不打乱，只是 attention mask 按排列顺序决定哪些 token 可见。因此某个 token 在某些排列中可以看到左侧和右侧上下文。

Two-stream Attention

naive permutation LM 有一个问题：预测位置 时，query 不能看到自己的内容 ，但 hidden state 又需要知道当前位置。XLNet 用两条 stream 解决：content stream 编码内容，query stream 编码“要预测的位置”但不泄漏该位置内容。

XLNet 还直接引入 Transformer-XL 的 segment recurrence 和 relative position，因此长上下文能力比普通 BERT-style encoder 更强。

Reading Notes

XLNet 的优点是目标函数更接近真正 likelihood，避免 [MASK]。缺点是实现和训练更复杂，两条 stream 加排列 mask 的工程成本高。后来的 RoBERTa 说明 BERT 如果用更多数据、更大 batch、更长训练，也能非常强。因此 XLNet 更像是“目标函数探索”的重要分支，而不是最终替代 BERT 的路线。

Takeaway

XLNet 值得记住三点：

  • 用 permutation order 获得双向上下文，而不是 corruption；
  • two-stream attention 防止 target token 内容泄漏；
  • 与 Transformer-XL 结合，说明位置编码和 recurrence 可以服务于预训练目标。

它对理解 BERT/GPT 目标函数差异很有帮助：不是所有双向上下文都必须通过 MLM 得到，也不是所有 autoregressive 都只能左到右。

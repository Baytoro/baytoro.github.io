End-to-End Object Detection with Transformers

H.J. Chen
  2020-08-21 2020-08-21 Created  
  • Paper Reading 
 
  • AIGC 
  • | Transformer 
  • | Vision 

Carion et al. End-to-End Object Detection with Transformers. ECCV 2020.

Paper

DETR is worth reading because it changes the shape of the detection problem. Instead of predicting dense anchors, ranking proposals, and cleaning duplicates with NMS, it predicts a fixed-size set of objects and trains the model with a one-to-one matching loss.

That sounds simple only after the paper exists. The key engineering move is to make “object slots” explicit through learned decoder queries, then force those slots to compete for ground-truth boxes through Hungarian matching.

Motivation

The first figure is the whole paper in one diagram. A CNN extracts image features, a Transformer reasons over them, and a fixed number of predictions is matched against the ground-truth set. A query that does not match any object is trained as the no-object class.

The important contrast with Faster R-CNN style detectors is not just the use of attention. DETR removes several hand-designed detection components:

  • no anchor boxes;
  • no region proposal network;
  • no NMS;
  • no class-specific duplicate suppression heuristic.

The model can do that because the loss itself enforces one prediction per object.

Architecture

The architecture has four parts:

  1. A CNN backbone maps the image to a lower-resolution feature map.
  2. A linear projection converts the CNN channels into the Transformer hidden dimension.
  3. A Transformer encoder adds global context over the flattened feature map, with positional encodings injected because attention is otherwise permutation-invariant.
  4. A Transformer decoder consumes learned object queries and outputs one embedding per query. Each embedding goes through small FFNs for class prediction and normalized box coordinates.

I read the object queries as learned detection slots. They are not proposals with coordinates. They are trainable vectors that ask the decoder to retrieve an object from the encoded image. Since the number of queries is larger than the expected number of objects, unused slots are trained to predict no object.

This design is clean, but it also explains why optimization is harder than in anchor-based detectors. Early in training, a query has no obvious spatial prior. The model must learn both where to attend and how to allocate queries to instances.

Set Prediction Loss

DETR trains on unordered sets. If the ground truth has M objects and the model emits N predictions with N >= M, the target set is padded with no-object entries. The matching step searches for the best permutation:

The one-to-one matching is the reason DETR does not need NMS. Two queries can still predict similar boxes, but only one of them receives the object match; the other is pushed toward no-object.

COCO Results

The main COCO table is more nuanced than “Transformer beats detector.” With ResNet-50, DETR reaches the same AP as Faster R-CNN-FPN+:

Method AP AP50 AP75 APS APM APL
Faster R-CNN-FPN+ 42.0 62.1 45.5 26.6 45.4 53.4
DETR 42.0 62.4 44.2 20.5 45.8 61.1
Faster R-CNN-R101-FPN+ 44.0 63.9 47.8 27.2 48.1 56.0
DETR-DC5-R101 44.9 64.7 47.7 23.7 49.5 62.3

The pattern is clear: DETR is strong on large objects and weak on small objects. That matches the architecture. The model reasons globally, but the original feature resolution and attention pattern are not ideal for dense small-instance localization.

Encoder Ablation

The encoder ablation makes the global reasoning argument more concrete. Removing the encoder gives 36.7 AP. Six encoder layers give 40.6 AP, and twelve layers give 41.6 AP. The gain is especially visible on large objects:

Encoder layers AP APS APM APL
0 36.7 16.8 39.6 54.2
3 40.1 18.5 43.8 58.6
6 40.6 19.9 44.3 60.2
12 41.6 19.8 44.9 61.9

This is one of the more useful figures for implementation intuition. The encoder is not a cosmetic Transformer block placed after a CNN. It materially improves scene-level reasoning and query assignment.

Attention And Segmentation

The attention visualization is a good sanity check. Encoder attention follows object boundaries instead of only local texture. That does not prove the model “understands” the scene, but it explains why a global self-attention layer can help with object separation and large-object detection.

The panoptic extension is also important. DETR’s box queries can be reused as instance-level handles: attach mask heads to the decoder outputs, combine them with per-pixel features, and predict segmentation masks. The paper reports competitive panoptic results without changing the core set-prediction idea.

Takeaway

DETR’s contribution is the combination, not any single component:

  • object detection as set prediction;
  • learned object queries as fixed prediction slots;
  • Hungarian matching as the training mechanism that removes duplicate predictions;
  • Transformer encoder-decoder for global assignment and scene reasoning.

The original version also has visible costs. It converges slowly, needs long training schedules, and underperforms on small objects. Later work such as Deformable DETR attacks exactly these points with sparse multi-scale attention and faster convergence. Still, DETR is the clean baseline to understand first because it makes the detector pipeline much less hand-engineered.

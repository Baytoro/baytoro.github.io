Linformer: Self-Attention with Linear Complexity

H.J. Chen
  2020-11-21 2020-11-21 Created  
  • Paper Reading 
 
  • LLM 
  • | AIGC 
  • | Transformer 

Wang S, Li B Z, Khabsa M, et al. Linformer: Self-Attention with Linear Complexity. 2020.

Paper

Linformer is one of the clean efficient-attention papers: it makes a structural claim about self-attention, then turns that claim into a simple layer change. The claim is that the self-attention context mapping is often low-rank, so the model does not need to materialize the full n x n attention map for every head.

This is approximate attention. It is not the same kind of optimization as FlashAttention, which computes exact attention with better IO behavior.

Why This Matters

The standard Transformer attention pattern has quadratic time and memory in sequence length:

Linformer projects keys and values along the sequence dimension before attention:

If k is treated as a small fixed projection dimension, the layer becomes linear in n.

The comparison table frames Linformer against other sequence models. The pitch is not only lower asymptotic complexity; it also keeps one sequential operation like a standard Transformer layer, unlike recurrent models.

Low-Rank Evidence

The paper first inspects pretrained Transformer attention matrices from RoBERTa-base and RoBERTa-large. The singular-value curves show that much of the mass is concentrated in a relatively small number of directions, especially in higher layers. This is the empirical basis for replacing the full context matrix with a low-rank approximation.

I read this figure as a useful diagnostic, not a universal proof. Some heads, tasks, or positions may need higher-rank interactions. Linformer is betting that the common case can be compressed enough to make the tradeoff worthwhile.

Layer Design

The layer keeps the usual query projection, but applies learned projection matrices to keys and values across the sequence dimension. In the paper notation, each head can use matrices shaped like k x n to reduce the token axis before attention.

The authors also discuss sharing these projection matrices:

Sharing strategy Meaning Practical effect
Headwise sharing heads share projection matrices fewer extra parameters than per-head projections
Key-value sharing key and value projections share parameters reduces the projection overhead further
Layerwise sharing layers share projection matrices smallest projection-parameter footprint

The strongest practical setting in the downstream table uses shared key/value projections and layerwise sharing, which is a useful signal: the benefit is not only from adding more parameters.

Pretraining Curves

The pretraining plots check several knobs:

  • larger k improves the approximation;
  • k = 128 works reasonably for n = 512, while k = 256 is stronger for longer settings;
  • sharing projection matrices does not destroy convergence;
  • fixing k = 256 while increasing n still gives similar final validation perplexity.

The last point is the important one for the paper’s linear-time claim. If quality collapsed whenever n increased with fixed k, the asymptotic story would not matter much in practice.

Downstream Results

The downstream numbers are close to RoBERTa-base on SST-2, IMDB, QNLI, and QQP. The table reports a RoBERTa-base average of 92.25. A Linformer model with n = 512, k = 256, shared key/value projections, and layerwise sharing reaches 92.30. With n = 1024, k = 256, and the same sharing pattern, it reaches 92.18.

That is the core empirical bargain: similar benchmark quality while avoiding the quadratic attention map.

Efficiency

Table 3 measures inference-time speed and memory savings against a standard Transformer on a 16GB Tesla V100. Even at n = 512, k = 128, the paper reports 1.5x faster inference and 1.7x lower memory. At long sequence lengths the savings grow quickly; for example, n = 65536, k = 256 reports 18x faster inference and 52x lower memory.

These numbers depend on the benchmark setup and implementation, but the direction is expected. Once the full n x n attention map disappears, the long-sequence memory curve changes substantially.

Takeaway

Linformer is attractive because the change is easy to understand: compress the sequence axis of keys and values, then attend to the compressed representation. It gives a clean path from quadratic attention to approximate linear attention.

The risk is exactly the assumption that makes it work. If a task really needs high-rank token-token interactions, fixed low-rank projections can throw away information before attention has a chance to use it. I would treat Linformer as a strong efficient-attention baseline for long-context experiments, but not as a drop-in replacement for exact attention when output equivalence matters.

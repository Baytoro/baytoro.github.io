Paper

GPT-3 是 GPT-2 路线的规模化版本，但它真正改变使用方式的是 few-shot prompting。模型参数不更新，任务通过自然语言说明和若干示例放进 context，模型直接续写答案。这是现代 LLM API 使用方式的早期定型。

Model Scale

GPT-3 最大模型 175B 参数，96 层，hidden size 12288，96 heads，context length 2048。结构仍然是 decoder-only Transformer，主要变化是规模、数据混合和训练稳定性。

In-context Learning

图里的多个任务随模型规模提升，few-shot 通常比 zero-shot 更强。这里的“few-shot”不是梯度微调，而是 prompt 里放几个输入输出示例。模型在前向传播中临时适配任务，相当于把任务描述编码进 hidden state。

这种能力有边界：它依赖 prompt 格式、示例选择、任务是否在预训练分布中出现过。GPT-3 也会在算术、事实一致性、长链推理上失败。论文同时强调了 bias、toxicity、data contamination 等问题。

Reading Notes

GPT-3 最值得复习的不是单个 benchmark，而是 evaluation protocol：zero-shot、one-shot、few-shot 三种设置明确区分，且都不更新参数。这为后续 instruction tuning、RLHF、tool use 奠定了接口基础。

Takeaway

GPT-3 的核心结论是：足够大的自回归语言模型可以把一部分“学习”推到上下文里完成。它让 prompt 从输入文本变成任务接口，也让预训练模型从 feature extractor 变成直接可用的通用模型。后续 InstructGPT 解决的正是 GPT-3 虽能续写但不总是愿意按人类意图回答的问题。

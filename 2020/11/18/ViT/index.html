Paper

ViT 的关键不是“把 Transformer 用到图像上”这么简单，而是它有意减少 CNN 的局部归纳偏置：把图像切成 patch，当成 token 序列送进标准 Transformer encoder。结果说明，只要预训练数据足够大，Transformer 可以学到强视觉表示。

Patch as Token

之后就是标准 Transformer encoder。分类时取 [class] token 的输出接 MLP head。

Data Scale Matters

ViT 在 ImageNet-21k/JFT 这类大数据上预训练后效果很强，但在小数据上不如带 CNN inductive bias 的模型稳定。这说明 patch token 方案不是免费替代 CNN：缺少局部性和平移等归纳偏置后，模型更依赖数据规模。

Takeaway

ViT 开启了视觉 Transformer 主线：

  • image patch = token；
  • Transformer encoder 成为通用视觉 backbone；
  • 大规模预训练弥补归纳偏置不足；
  • 后续 Swin、DeiT、MAE 等工作分别从层级结构、蒸馏、masked image modeling 改进。

这篇文章对 NAS/视觉 backbone 也很重要，因为它把搜索空间从 CNN cell 推向 attention/window/patch embedding 等新维度。

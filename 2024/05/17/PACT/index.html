Paper: PACT: Parameterized Clipping Activation for Quantized Neural Networks

PACT is about a small parameter that causes a large amount of pain: the activation clipping threshold. If the threshold is too small, useful signal saturates. If it is too large, the quantization grid wastes levels on rare outliers. PACT makes this threshold learnable.

Motivation

Weights are static after training, so weight ranges can be inspected and calibrated layer by layer. Activations are dynamic and input-dependent. Low-bit activation quantization becomes fragile because a few large values can force a large quantization step for every ordinary value.

The paper’s plots show the central tradeoff: activation clipping can recover low-bit accuracy, but the clipping point must be chosen carefully. PACT treats the clipping point as a trained model parameter instead of a fixed hyperparameter.

Results

PACT is evaluated on low-bit CNN quantization. The key improvement appears at 2-bit and 4-bit activation precision, where range selection matters most. Compared with fixed clipping or naive quantization, learned clipping recovers much more accuracy.

The method is also simple to combine with weight quantization. It does not require an exotic codebook or complicated runtime format; it only changes how the model learns activation ranges before deployment.

Connection To LLM Quantization

PACT is a CNN-era paper, but it is directly connected to LLM activation quantization. LLM.int8(), SmoothQuant, RPTQ, OmniQuant, and QuaRot all address activation outliers in different ways. PACT’s version of the problem is the earliest clean form: the activation range is a parameter worth optimizing, not a statistic to blindly copy from min/max calibration.

The limitation is that PACT assumes QAT. For huge LLMs, full QAT is usually too expensive, so later methods prefer post-training transformations or calibration-only optimization. Still, the clipping/resolution tradeoff is the same.

Why Clipping Is Not Just Calibration

A fixed activation range is brittle because it is chosen before the model adapts to quantization noise. PACT changes the training problem: the network can learn to reduce outliers if doing so improves low-bit accuracy.

The learned parameter searches this tradeoff per layer. This is more expressive than using a global percentile threshold.

The paper also matters because activation clipping is still a central LLM problem. SmoothQuant can be viewed as avoiding an impossible clipping choice by migrating activation magnitude into weights. OmniQuant returns to the PACT-like idea of learning clipping parameters, but in a post-training LLM setting.

Limitation

PACT assumes QAT. For small CNNs, that is reasonable. For a 70B LLM, full QAT is expensive and often unavailable. So PACT is best read as a conceptual baseline for learnable activation ranges, not as the direct deployment method for current LLMs.

Reading Detail

This is why PACT is more than simply adding a ReLU6. The clipping value is optimized under the task loss, so the model can decide how much tail mass to sacrifice. The paper also uses regularization on to prevent it from growing until quantization becomes ineffective.

For LLM quantization, the same idea reappears in a different form. SmoothQuant and OmniQuant do not just accept activation outliers as a given; they alter the activation range before quantization. PACT is an earlier CNN-era example of making the activation distribution itself part of the quantization problem.

Experiment Reading

The interesting experiment setting is very low activation precision. At 8 bits, many activation clipping choices look acceptable. At 4 bits or below, the clipping threshold becomes a major part of the model. If is too high, most quantization levels are spent on rarely used large activations. If is too low, the model saturates too many features and loses information.

This is why I would plot both accuracy and learned by layer. Early layers and late classifier-adjacent layers often prefer different clipping behavior. A single global clipping policy would hide that. The paper’s contribution is letting the task loss choose those thresholds while the model is trained with quantization noise.

For modern deployments, PACT is still relevant as a design pattern: when a tensor distribution is hostile to low-bit quantization, first ask whether the distribution can be shaped by a learnable parameter, then ask whether that parameter can be fused away at inference.

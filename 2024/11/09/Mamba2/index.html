Mamba-2: Structured State Space Duality

Paper: Transformers are SSMs: Generalized Models and Efficient Algorithms Through Structured State Space Duality

Code: https://github.com/state-spaces/mamba

Mamba-2 is not just a faster Mamba kernel. The paper’s main move is to put selective state space models and attention into one algebraic picture, then use that picture to design a sequence mixer that is friendlier to GPU matrix multiplication.

The name of the bridge is structured state space duality (SSD). The useful mental model is:

  • SSM recurrence is a structured lower-triangular matrix transformation.
  • Attention is also a matrix transformation, but usually with a dense or masked query-key matrix.
  • If the attention mask has the right structure, an attention-like quadratic form and an SSM-like linear recurrence can describe the same computation.

That duality matters because implementation details dominate long-context models. A recurrence may be asymptotically linear, but if it is serialized or misses tensor cores, it can lose to a quadratic attention kernel on real hardware. Mamba-2 uses SSD to keep the state-space flavor while making the main training computation look more like block matrix multiplication.

Roadmap

The paper is organized around the diagram above. It first relates state space models to semiseparable matrices, then generalizes attention into structured masked attention, then shows that the two families overlap. The Mamba-2 architecture is the practical result of that overlap.

This is a useful framing because “attention vs SSM” is often discussed as if the two are separate model families. Mamba-2 argues that the boundary is more about structure and algorithms than about a hard mathematical divide.

SSMs As Structured Matrices

A state space layer can be written as a recurrence:

If we unroll the recurrence over the whole sequence, the layer becomes a lower-triangular matrix multiplication from inputs to outputs . The matrix is not arbitrary. Its off-diagonal blocks have low-rank structure because information has to pass through a finite-dimensional hidden state.

The paper describes this matrix family as semiseparable. That is the first important abstraction: an SSM is not only a recurrence, it is also a structured sequence transformation matrix.

This view explains why SSMs have multiple possible implementations:

  • Recurrent scan: process token by token while carrying the hidden state.
  • Convolution: when parameters are time-invariant or structured enough, use a convolution-like representation.
  • Matrix multiplication: exploit the semiseparable matrix structure in blocks.

Mamba-1 leaned heavily on the scan view. Mamba-2 keeps the recurrence interpretation but makes the matrix view central to the algorithm.

Structured Masked Attention

Attention can also be written as a sequence transformation matrix. Standard causal attention computes something like a query-key interaction, applies a causal mask, then uses the result to mix values. Mamba-2 generalizes this idea into structured masked attention:

Here is not just the usual triangular causal mask. It can be any structured mask that gives the attention matrix useful algebraic properties.

This figure is one of the most important in the paper. Different choices of recover different efficient-attention-like mechanisms:

  • A causal mask gives linear attention style structure.
  • A decay mask connects to RetNet-like behavior.
  • A 1-semiseparable mask gives the SSD case.
  • Other structured masks can produce Toeplitz or Fourier-style attention variants.

The point is not that all of these models are identical. The point is that attention can be constrained with structure, and those structures can be studied with the same matrix tools used for SSMs.

State Space Duality

SSD is the intersection: a layer that has both an SSM-style recurrent form and an attention-style quadratic form.

This is where the title “Transformers are SSMs” comes from. The paper is not claiming that a vanilla Transformer block is secretly the same as a Mamba block. The narrower and more useful claim is that a family of structured masked attention layers can be represented as state space models, and a family of structured state space models can be computed through attention-like matrix operations.

The dual form is useful because each side gives something different:

  • The recurrent form gives compact inference state.
  • The quadratic matrix form exposes parallel training algorithms.
  • The structured matrix view gives a way to reason about memory, compute, and block decomposition.

That is a better engineering tradeoff than treating recurrence and attention as two unrelated toolboxes.

The SSD Algorithm

The algorithmic problem is straightforward: how can we compute an SSM-like transformation without paying for a fully serial scan during training?

Mamba-2 uses a block decomposition of the semiseparable matrix. Diagonal blocks are local within a chunk. Off-diagonal blocks communicate through the hidden state. That creates a mixed algorithm: matrix multiplication inside chunks, state passing between chunks.

The four pieces are:

  1. Compute the diagonal blocks, which correspond to intra-chunk token interactions.
  2. Compute each chunk’s contribution to the next hidden state.
  3. Scan over chunk states instead of individual token states.
  4. Convert the propagated states back into output contributions for later chunks.

This is the part of the paper that feels most like a systems result. The math gives the decomposition, but the reason to care is that the expensive work can be arranged as larger matrix multiplications. That is exactly the kind of operation modern GPUs are built to run well.

For long sequences and moderate state sizes, this is the design goal: compact recurrent state for inference, but training kernels that still use the hardware efficiently.

Mamba-2 Block Design

Mamba-2 also changes the neural network block around the sequence mixer. This is easy to underplay, but it matters for large model training.

The original Mamba block is sequential: some projections are produced after the input has already passed through part of the block. Mamba-2 treats the SSD layer as a map from to , so it can produce these inputs in parallel at the beginning of the block.

The paper highlights three practical changes:

  • The data-dependent SSM parameters are produced at the beginning of the block.
  • An extra normalization layer is added for stability.
  • The and projections use a single head shared across the heads, analogous to multi-value attention.

This is partly a model-design decision and partly a distributed-training decision. Parallel projections fit existing Transformer-style tensor parallel patterns much better than a strictly sequential block.

The left side of the figure shows tensor parallelism for the Mamba-2 block. The right side shows sequence/context parallelism: each device can handle a segment of the sequence and pass the recurrent state across segment boundaries. That is a cleaner communication pattern than full attention, where query blocks and key blocks interact quadratically across devices.

Synthetic Recall

The paper uses multi-query associative recall (MQAR) to test whether the model can remember multiple key-value associations across a sequence. This is a direct stress test for recurrent models because all relevant information must be compressed into the recurrent state.

The result is a good diagnostic for Mamba-2’s larger state sizes. Mamba-1 with a small state struggles on this task. Mamba-2 improves strongly as the state dimension grows from to and . At the shown sequence lengths, the larger-state Mamba-2 curves approach near-perfect accuracy much faster than the small-state recurrent baseline.

I would read this figure as evidence for capacity, not as a complete language-modeling result. MQAR is synthetic and narrow, but it exposes a failure mode that recurrent sequence mixers must address before they can be trusted on long-context tasks.

Language Modeling Results

The scaling-law plot compares Mamba-2 with Mamba and a strong Transformer++ recipe on The Pile at sequence length 8192.

The Mamba-2 line is consistently below the Mamba and Transformer++ lines in this plot, meaning lower perplexity at similar theoretical FLOPs. The paper also states that Mamba-2 is Pareto dominant in wall-clock time in this setting, which is the stronger systems claim.

The zero-shot table is useful because it checks whether this efficiency story transfers to normal language-model evaluation.

At the small scale, Mamba-2-780M reaches an average score of 53.5, compared with 53.0 for Mamba-790M and 49.0 for Pythia-1B in the table. At 2.7B, Mamba-2 reaches 60.2 average accuracy, ahead of Mamba-2.8B’s 59.9 and much higher than Pythia-2.8B’s 55.7 under the reported setup.

Model Reported scale Average accuracy
Pythia 1B 49.0
Mamba 790M 53.0
Mamba-2 780M 53.5
Pythia 2.8B 55.7
Mamba 2.8B 59.9
Mamba-2 2.7B 60.2

The result is not a universal win on every single column. For example, Mamba-2-2.7B is slightly behind Mamba-2.8B on ARC-E and OpenBookQA in this table. But the aggregate result supports the paper’s main claim: the new architecture is competitive as a language model, not only as a kernel benchmark.

Speed Benchmarks

The efficiency benchmark isolates the SSD algorithm against scan, convolution, and FlashAttention-2 style baselines on an A100 80GB PCIe GPU.

The left plot shows sequence-length scaling. For state dimension 64, SSD is faster than the Mamba fused scan in the reported range and faster than FlashAttention-2 from around sequence length 2K onward. The right plot fixes sequence length at 4K and varies state dimension. The scan implementation slows down roughly linearly as the state dimension grows, while SSD remains much flatter.

The important caveat is that this is an algorithm/kernel result, not a full serving-system benchmark. A complete model has projections, normalization, residual paths, memory traffic, batching behavior, and framework overhead. Still, this benchmark explains why the paper cares so much about the matrix view: the same SSM math becomes much more attractive when the implementation reaches tensor-core-friendly operations.

Hybrid Attention Layers

Mamba-2 does not conclude that attention should disappear. The paper tests hybrids that insert a small number of attention layers into a mostly SSD model.

For a 350M model with 48 layers, pure Mamba-2 reports perplexity 8.60 in this table. Adding a few attention layers helps; 6 attention blocks gives the best shown perplexity at 8.26. The paper summarizes this as roughly a 10% attention-layer ratio working well.

The 2.7B hybrid table gives the same message in a downstream-evaluation setting.

Mamba-2 alone reaches 60.2 average accuracy, equal to the Transformer++ row in this table. Adding a small number of attention layers improves the best average to 61.0 for Mamba-2-Attention. The Mamba-2-MLP-Attention variant reaches 60.7.

Model Layer mix Average accuracy
Transformer++ Attention + gated MLP 60.2
Mamba-2 SSD only 60.2
Mamba-2-MLP SSD + gated MLP 59.6
Mamba-2-Attention Mostly SSD, 6 attention layers 61.0
Mamba-2-MLP-Attention SSD + MLP + attention 60.7

I like this result because it avoids an ideological conclusion. SSD is useful, but a little attention still helps. A practical long-context architecture may not need to be pure recurrence or pure attention; the better answer can be a controlled mixture.

Practical Notes

Where Mamba-2 looks attractive:

  • Long-context inference where compact recurrent state matters.
  • Training regimes where full attention memory becomes the limiting factor.
  • Models that need better tensor-parallel friendliness than the original Mamba block.
  • Research on hybrid architectures that use attention only where it pays for itself.

Where I would be careful:

  • Short sequences, where a highly optimized Transformer stack may still be simpler and fast enough.
  • Tasks requiring arbitrary pairwise token interaction in many layers.
  • Production inference stacks that already depend on mature attention-specific kernels, caching, and batching infrastructure.
  • Claims based only on the SSD kernel benchmark without measuring the full model path.

The most useful implementation lesson is that asymptotic complexity is not enough. Mamba-2 improves the algorithmic shape, but the real win comes from matching that shape to GPU primitives.

Takeaway

Mamba-2 is valuable because it explains why the SSM/attention boundary is softer than it looks. Semiseparable matrices give SSMs a matrix form; structured masks give attention a recurrent form; SSD is the overlap where both interpretations are available.

The practical result is a sequence mixer with compact inference state, parallel training algorithms, and a block design that fits large-scale training better than Mamba-1. The paper is strongest when read as both theory and systems work: the duality is interesting, but the reason it matters is that it produces a model and kernel path that can actually run well.

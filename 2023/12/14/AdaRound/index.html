Paper: Up or Down? Adaptive Rounding for Post-Training Quantization

AdaRound is a small but important PTQ paper. It does not invent a new quantization grid, a new integer kernel, or a full retraining recipe. It asks a narrower question: after the scale is fixed, should each weight round down or round up?

The default answer is nearest rounding. That is optimal if the objective is only element-wise weight error. The paper’s point is that the model does not consume weights element by element. It consumes , and different rounding errors interact through activations and loss curvature.

The paper makes this concrete by quantizing only the first layer of ResNet18 to 4-bit weights. Rounding every value up or down is catastrophic, but some stochastic rounding samples beat nearest rounding by a large margin.

Table 1 from the paper: nearest rounding reaches 52.29% top-1 accuracy for the first layer, while the best of 100 stochastic samples reaches 63.06%.

The cost from the Hessian proxy correlates with ImageNet validation accuracy. This is the empirical reason the paper treats rounding as an optimization problem instead of a per-weight nearest-neighbor rule.

Ablation Notes

The best ablation in the paper is the path from the original Hessian problem to the practical local objective. On ResNet18, the Hessian proxy, local MSE loss, and continuous relaxation all beat nearest rounding by a large margin.

This table is the main justification for the approximations. Nearest rounding on all layers gives 23.99%, while the continuous local relaxation gives 66.56%. The method is not just a convenient relaxation; it preserves most of the benefit from optimizing rounding.

The design choices are also worth reading because they explain why AdaRound is not just “train a quantizer with STE”.

The explicit regularizer is more stable than temperature annealing alone, and the rectified sigmoid gives the best all-layer number.

Asymmetric reconstruction is a practical improvement: layer-wise reconstruction gives 66.56%, while adding asymmetric reconstruction and ReLU gives 68.60%.

The STE baseline is strong but still worse. My read is that AdaRound’s restriction is a feature: it only chooses between the two adjacent quantization values, while STE optimization has a biased gradient and a less controlled search space.

The quantization grid still matters, but AdaRound improves all tested grids. The best result here is with the preactivation-MSE grid, but the paper keeps the simpler grid for the remaining experiments.

Calibration Data

AdaRound is a PTQ method, so the amount and source of calibration data matter. The paper uses unlabeled images and optimizes layer-wise with Adam. The default setup is 1024 ImageNet training images, batch size 32, 10k iterations, and fixed 4-bit symmetric per-layer weight quantization.

The method is not extremely data hungry in this CNN setting. Even 256 images keep the model near the final result, and data from MS COCO or Pascal VOC is close to ImageNet calibration. This does not mean calibration is irrelevant; it means the local reconstruction objective is not overfitted to labels or full-dataset training.

Main Results

The main ImageNet result is the strongest evidence that the method is useful beyond a first-layer toy case.

For 4-bit weights and FP32 activations, AdaRound reaches 68.71% on ResNet18 and 75.23% on ResNet50, within about 1% of the FP32 baselines in the table. With 8-bit activation quantization added, the numbers barely move for these models.

The paper also includes semantic segmentation to show the method is not only an ImageNet classification trick.

On DeeplabV3+ with a MobileNetV2 backend, nearest 4/8 quantization collapses to 6.09 mIOU, while AdaRound with 4-bit weights and 8-bit activations reports 70.86 mIOU versus 72.94 full precision.

Implementation Reading

The layer-wise workflow I would implement is:

  1. Fold batch normalization into neighboring weights.
  2. Choose the quantization scale and clipping range before AdaRound.
  3. Cache calibration inputs for the current layer.
  4. Optimize with the asymmetric reconstruction loss and the annealed regularizer.
  5. Convert to hard 0/1 rounding decisions.
  6. Move to the next layer with previous layers already quantized.

The important debugging signal is the learned rounding mask. If almost every decision matches nearest rounding, the optimizer is not doing much. If many decisions flip but reconstruction error does not improve, the annealing schedule, calibration cache, or scale choice is probably wrong.

Link To Later PTQ Work

AdaRound is one of the bridges from old range-calibration PTQ to solver-style PTQ. Later methods widen or change the local objective, but the core lesson stays the same.

  • AdaRound optimizes up/down rounding decisions for a layer.
  • BRECQ keeps adaptive rounding but reconstructs larger blocks.
  • GPTQ scales a second-order reconstruction view to LLM weight matrices.
  • AWQ keeps activation-important weight channels accurate through scaling and quantization choices.

The most direct conceptual link is GPTQ. Both methods reject independent nearest rounding. AdaRound uses a soft relaxation and local reconstruction; GPTQ uses a sequential second-order update. Different solver, same warning: the cost of a rounding error depends on how the layer uses that weight.

Limitations

AdaRound was evaluated mainly on CNN PTQ. It is not a complete deployment story for modern LLM inference: there is no packed-weight kernel format discussion, no KV-cache issue, and no activation-outlier treatment like SmoothQuant.

The layer-wise reconstruction objective is also local. It is much better than per-weight nearest rounding, but it still cannot fully model error interactions across residual blocks or whole networks. This is why BRECQ’s block reconstruction is a natural follow-up.

Finally, AdaRound fixes the quantization grid before optimizing rounding. That separation makes the method simple, but it also means a bad scale choice can limit the final result. I would treat scale selection, calibration data, and annealing schedule as the three reproduction knobs to check first.

Takeaway

AdaRound’s value is not only the 4-bit CNN accuracy. The important idea is that rounding is a discrete optimization problem with structure. Nearest rounding minimizes the wrong objective; calibration-driven reconstruction is a better proxy for what the model actually computes.

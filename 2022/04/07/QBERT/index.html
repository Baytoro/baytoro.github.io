Paper: Q-BERT: Hessian Based Ultra Low Precision Quantization of BERT

Q-BERT is an early but still useful paper for understanding why transformer quantization cannot be treated as a simple “pick one bit-width for every matrix” problem. The paper studies fine-tuned BERTBASE models with second-order information, then uses that signal to decide where low precision is safe and where the model needs more bits. The two main tools are Hessian-aware mixed precision and group-wise quantization.

My reading focus is not only the headline compression number. The important part is the failure mode: BERT layers, attention heads, feed-forward blocks, word embeddings, and position embeddings do not react to quantization in the same way. Q-BERT is valuable because it makes that statement measurable.

Motivation

The deployment problem in the paper is straightforward. BERTBASE is accurate on downstream NLP tasks, but it is expensive for edge inference. The paper reports the full-precision parameter footprint as roughly 91 MB for the embedding table, 325 MB for the encoder stack, and only about 0.01 MB for the output/classifier layer. Since the classifier is negligible, Q-BERT focuses on quantizing the embedding and encoder parameters.

The paper evaluates four task families:

Task Dataset Metric used in the paper
Sentiment classification SST-2 Accuracy
Natural language inference MNLI Matched / mismatched accuracy
Named entity recognition CoNLL-03 F1
Machine reading comprehension SQuAD EM and F1

The baseline approach, called DirectQ in the paper, quantizes BERT without Hessian-aware mixed precision or group-wise quantization. DirectQ is useful as a sanity check because it shows how much accuracy is lost when the quantization recipe ignores transformer structure. The gap is huge at low bit-widths, especially on SQuAD.

Hessian-Aware Mixed Precision

Q-BERT builds on the HAWQ idea: layers with larger Hessian spectrum are more sensitive to quantization and should receive more bits. The challenge is that each BERTBASE encoder layer has millions of parameters, so explicitly materializing a Hessian matrix is not practical. Q-BERT does not form the Hessian. It estimates the top eigenvalue with Hessian-vector products and power iteration.

SQuAD is the outlier. The paper reports that the fine-tuned SQuAD model has not reached a clean local minimum: the visualized landscape contains negative curvature directions, and the eigenvalue distribution is much more unstable. Once is computed, Q-BERT sorts the encoder layers by sensitivity and assigns higher precision to more sensitive layers. The bit assignment is task-specific because the Hessian statistics are task-specific.

This is a useful table to read slowly. For SST-2, layers 4 to 9 are assigned 3 bits while layers 1 to 3 and 10 to 12 are assigned 2 bits. For MNLI, layers 5 to 8 get 3 bits. For CoNLL-03, the higher-bit region shifts toward layers 2 to 5. SQuAD gives 3 bits to layers 4 to 9. The bit pattern is not universal; it is derived from the downstream fine-tuned model.

Group-Wise Quantization

Mixed precision decides how many bits a layer or module gets. Group-wise quantization decides what dynamic range those bits should cover.

Q-BERT therefore partitions matrices into groups, each group having its own quantization range and lookup table.

Group-wise quantization illustrated on value matrices. Layer-wise quantization gives the whole tensor one range; group-wise quantization gives each head or sub-head group its own range.

There are three granularity levels in the figure:

  • Layer-wise: the whole 3D tensor uses one quantization range.
  • Head-wise: each attention head matrix uses one range.
  • Finer group-wise: each head matrix is further partitioned along output neurons.

The paper evaluates the number of groups directly.

Group-count ablation with 4-bit weights, 8-bit embeddings, and 8-bit activations. The paper uses 128 groups for the main experiments.

The numbers are clear:

Number of groups SST-2 MNLI-m/mm CoNLL-03
Baseline 93.00 84.00 / 84.40 95.00
1 85.67 76.69 / 77.00 89.86
12 92.31 83.30 / 83.55 94.42
128 92.66 83.89 / 84.17 94.90
768 92.78 84.00 / 84.20 94.99

Layer-wise quantization, which corresponds to one group, loses about 7 points on these tasks. Moving to 12 groups recovers most of the loss. Moving from 12 to 128 still helps. Moving from 128 to 768 gives almost no additional accuracy. The paper chooses 128 because it balances accuracy with metadata and lookup-table overhead.

This is one of the most transferable lessons from Q-BERT. The exact architecture is BERT, but the idea reappears in modern LLM weight-only quantization: group size is not cosmetic. It controls how much local dynamic-range information survives.

Main Results

All non-baseline results in the main table use 8-bit activations. Q-BERT uses 128 groups in each layer. The table compares three ideas:

  • DirectQ: direct quantization without group-wise quantization or mixed precision.
  • Q-BERT: group-wise quantization with a fixed bit-width.
  • Q-BERTMP: group-wise quantization with Hessian-aware mixed precision.

Main BERTBASE quantization results on SST-2, MNLI, CoNLL-03, and SQuAD.

A compact reading of the table:

Task Baseline Strong low-bit Q-BERT result DirectQ failure mode
SST-2 93.00 Acc 92.08 Acc with 2/3-bit Q-BERTMP, 48.1 MB 2-bit DirectQ falls to 80.62
MNLI 84.00 / 84.40 Acc 81.75 / 82.29 with 2/3-bit Q-BERTMP, 46.1 MB 2-bit DirectQ falls to 53.29 / 53.32
CoNLL-03 95.00 F1 94.37 F1 with 2/3-bit Q-BERTMP, 45.0 MB 2-bit DirectQ falls to 54.50
SQuAD 81.54 EM / 88.69 F1 79.29 EM / 86.95 F1 with 2/3-bit Q-BERTMP, 48.1 MB 2-bit DirectQ falls to 4.77 / 10.32

Several observations matter more than the average compression ratio.

First, 4-bit direct quantization is already weak. On SQuAD, DirectQ with 4-bit weights and 8-bit embeddings gives 66.05 EM / 77.10 F1, while Q-BERT under the same bit-width gives 80.95 EM / 88.36 F1. That is the effect of group-wise quantization and quantization-aware tuning.

Second, uniform 2-bit Q-BERT is still too aggressive. Group-wise quantization helps, but it does not remove the need for mixed precision. For example, CoNLL-03 uniform 2-bit Q-BERT gets 91.06 F1, while 2/3-bit Q-BERTMP recovers to 94.37 F1. SST-2 moves from 84.63 with uniform 2-bit Q-BERT to 92.08 with 2/3-bit Q-BERTMP.

Third, SQuAD is consistently harder. Even with Q-BERT, SQuAD sees the largest degradation. The Hessian analysis gives a plausible reason: the fine-tuned SQuAD model has unstable curvature and negative curvature directions, so quantization is perturbing a model that is not sitting in a clean minimum.

The paper’s headline claim is that Q-BERT reaches up to 13x weight compression, 4x activation-size reduction, and 4x embedding-size reduction with at most 2.3 percent performance degradation. Reading the table, this claim is credible but conditional: it depends on QAT, group-wise quantization, task-specific Hessian analysis, and mixed precision.

Why Reversed Mixed Precision Fails

The most convincing ablation is the reversed mixed-precision assignment. If Hessian-aware sorting matters, then assigning lower bits to sensitive layers and higher bits to insensitive layers should be worse at the same model size.

Reversed mixed-precision assignment. Q-BERTMP-rev uses the same total size pattern but flips the bit allocation against the Hessian-aware assignment.

That is exactly what happens. On SQuAD, uniform 2-bit Q-BERT gives 69.68 EM / 79.60 F1. The reversed 2/3-bit assignment gives 69.71 EM / 79.39 F1, basically no improvement. The Hessian-aware 2/3-bit Q-BERTMP reaches 79.29 EM / 86.95 F1. The same trend appears on SST-2, MNLI, and CoNLL-03.

This ablation matters because mixed precision can otherwise look like a parameter-budget trick. The reversed setting shows that the allocation signal is doing real work.

Module Sensitivity

Q-BERT also studies which BERT modules are fragile. This section is more useful than it may look, because it separates “quantizing BERT weights” into multiple different problems.

Module sensitivity experiments. The top table isolates word and position embeddings; the bottom table compares multi-head attention with feed-forward layers.

The embedding results are sharp:

  • 8-bit word embedding and 8-bit position embedding are safe: SQuAD F1 is 88.47, close to the 88.69 baseline.
  • 4-bit word embedding with 8-bit position embedding is still tolerable: SQuAD F1 is 87.55.
  • 8-bit word embedding with 4-bit position embedding is bad: SQuAD F1 drops to 72.38.
  • 4-bit word and 4-bit position embedding together are catastrophic: SQuAD F1 drops to 61.70.

The interesting part is not just that embeddings are sensitive. Position embedding is much smaller than word embedding, but it is more fragile in this experiment. The paper interprets this as evidence that positional information is especially important for natural language understanding tasks. From an engineering perspective, this is a reminder that model-size contribution and quantization sensitivity are different axes. A small module can be worth keeping at higher precision.

The attention-vs-FFN experiment also has a clear conclusion. With embeddings and activations kept at 8 bits, the paper reduces either self-attention or fully connected layers by one extra bit:

  • 1/2-bit mixed precision for self-attention and 2/3-bit mixed precision for FFN gives SQuAD F1 75.81.
  • 2/3-bit mixed precision for self-attention and 1/2-bit mixed precision for FFN gives SQuAD F1 68.71.
  • 2/3-bit mixed precision for both gives SQuAD F1 86.95.

So in this setup, self-attention is more robust than the feed-forward network. Reducing FFN precision hurts more.

Mixed Precision for Embeddings

The main table uses 8-bit embeddings, so after encoder compression the embedding table becomes a large part of the remaining model size. The appendix explores a mixed embedding setting: 4-bit word embeddings and 8-bit position embeddings.

Embedding mixed-precision results. The paper uses 4-bit word embedding and 8-bit position embedding, with 128 groups for both encoder weights and embeddings.

This is a good compromise if the memory target is very strict. For example:

Task 2/3-bit weights + 8-bit embeddings 2/3-bit weights + 4/8-bit embeddings
SST-2 92.08 Acc, 48.1 MB 91.51 Acc, 36.9 MB
MNLI 81.75 / 82.29 Acc, 46.1 MB 81.00 / 81.65 Acc, 34.9 MB
CoNLL-03 94.37 F1, 45.0 MB 94.45 F1, 34.4 MB
SQuAD 79.29 EM / 86.95 F1, 48.1 MB 78.68 EM / 86.49 F1, 36.9 MB

The drop is not free, but it is small enough that this setting is realistic for a tight memory budget. The key is that Q-BERT does not push position embeddings to 4 bits in this setting. It keeps the more sensitive position component at 8 bits.

Attention Distribution Analysis

The paper also checks whether the quantized model preserves attention behavior. It computes KL divergence between the attention distribution of the quantized model and the full-precision baseline, for coordinated heads on the same input. Lower KL means the quantized attention pattern is closer to the baseline.

KL divergence over attention distributions. Q-BERT stays closer to the full-precision baseline than DirectQ across tasks and layers.

The qualitative result aligns with the accuracy tables. Q-BERT has consistently lower KL distance than DirectQ. This does not prove that attention distributions are the whole reason accuracy is preserved, but it is useful supporting evidence: group-wise quantization and QAT are not merely matching final labels; they also preserve more of the internal attention behavior.

Implementation Notes

A practical Q-BERT pipeline looks like this:

  1. Fine-tune a full-precision BERT model on the downstream task.
  2. Compute top Hessian eigenvalue distributions per encoder layer using matrix-free power iteration.
  3. Compute .
  4. Sort layers by and assign mixed precision under the target model-size budget.
  5. Apply group-wise uniform quantization, typically with 128 groups in the paper’s experiments.
  6. Use quantization-aware fine-tuning with STE.
  7. Keep small or sensitive modules at higher precision when the memory benefit is not worth the accuracy loss.

The method is not a pure post-training quantization method. It relies on quantization-aware fine-tuning, task-specific calibration, and Hessian-vector products. It is therefore heavier than modern one-shot weight-only LLM quantization methods. The upside is that the analysis is explicit: Q-BERT tells us which layers and modules are sensitive instead of only reporting a final compressed checkpoint.

There is also a hardware caveat around 3-bit execution. The paper notes that 3-bit arithmetic is not usually directly supported. A practical implementation may pack 3-bit values in memory and cast them to 4-bit or 8-bit execution units, preserving some memory-bandwidth benefit but not necessarily delivering ideal low-bit compute speedup. The 2/4-bit mixed-precision alternative is included partly for this reason.

Limitations

Q-BERT should be read as a BERT-era quantization paper, not as a complete recipe for current decoder-only LLM deployment.

First, the method is task-specific. The Hessian statistics are computed after downstream fine-tuning, and the bit assignment changes across SST-2, MNLI, CoNLL-03, and SQuAD. This is reasonable for fine-tuned BERT services, but it is less convenient for general-purpose foundation models that serve many tasks.

Second, the paper uses QAT. That makes the results stronger than simple PTQ, but it also means extra training cost and access to task data.

Third, group-wise quantization introduces scale/range metadata and lookup-table overhead. The paper’s group-count ablation is important because it shows why 128 groups is a reasonable point: 768 groups only improves accuracy by about 0.1 point while increasing overhead.

Fourth, the SQuAD analysis is a warning. If the full-precision model is not at a stable local minimum, second-order quantization sensitivity becomes harder to interpret and the quantized result is worse. The paper tried changing fine-tuning hyperparameters but found SQuAD quickly overfit, so fixing that training issue was outside its scope.

Takeaway

The core lesson of Q-BERT is that ultra-low-bit transformer quantization needs both sensitivity measurement and the right granularity. Hessian-aware mixed precision answers “which layers deserve more bits”; group-wise quantization answers “which sub-tensors deserve their own dynamic range.”

For this paper, the most reusable ideas are:

  • Use curvature or another sensitivity proxy before assigning bits.
  • Do not assume identical encoder layers have identical quantization sensitivity.
  • Treat word embedding, position embedding, self-attention, and FFN separately.
  • Group-wise ranges can recover most of the loss from low-bit quantization.
  • Very low memory size does not automatically imply practical acceleration unless the hardware path supports the chosen bit format.

Q-BERT is not the final form of LLM quantization, but it is one of the clean early papers showing that transformer compression is a structured problem. The model is not one tensor; it is a set of modules with different curvature, different value distributions, and different failure modes.

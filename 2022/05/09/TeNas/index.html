TE-NAS is a training-free NAS method with a theoretical flavor. It decomposes architecture quality into two aspects: trainability and expressivity. Trainability is estimated using the Neural Tangent Kernel condition number; expressivity is estimated using linear regions.

Expressivity: Linear Regions

For ReLU networks, the input space is divided into piecewise-linear regions. More regions usually indicate stronger expressive capacity. TE-NAS estimates expressivity from activation patterns under random inputs.

The two scores should be used together:

Score Desired direction Failure if used alone
NTK condition number lower may prefer easy but underpowered networks
linear regions higher may prefer expressive but hard-to-train networks

Search Mechanism

TE-NAS prunes poor candidate operations based on these training-free scores. It does not train a supernet and does not use validation labels.

This avoids weight-sharing bias but introduces proxy sensitivity. NTK computation depends on initialization, batch choice, normalization handling, and numerical stability.

Takeaway

TE-NAS is best viewed as an architecture diagnostic method. It shows that initialization-time Jacobian and activation-pattern information can guide search, especially when training every candidate is too expensive.

Paper: ViTAS: Vision Transformer Architecture Search

Su X, You S, Xie J, Zheng M, Wang F, Qian C, Zhang C, Wang X, Xu C. ViTAS: Vision Transformer Architecture Search. ECCV 2022.

ViTAS is a Vision Transformer NAS paper, but the useful part is not only that it searches a better ViT backbone. The deeper point is about whether a one-shot Transformer supernet can rank candidate architectures fairly.

The paper’s diagnosis is sharp:

  • one-shot NAS trains a large supernet and lets candidate architectures inherit weights from it;
  • in width/dimension search, common ordinal sharing gives small dimensions the first channels;
  • those early channels are trained more often than later channels;
  • for ViTs, where token embeddings and FC projections dominate the block, this channel imbalance makes inherited accuracy a biased estimator;
  • if inherited accuracy is biased, the search loop can select architectures that merely received better shared weights.

ViTAS attacks this with cyclic weight sharing for token embedding dimensions, then adds identity shifting and a weak superformer training recipe to stabilize search.

All crops below are taken from the original PDF.

Why ViT NAS Is Not Just CNN NAS

Vision Transformers expose several architecture dimensions at once:

  • patch size or local/global attention granularity;
  • number of attention heads;
  • attention projection width;
  • MLP hidden width;
  • operation type in each layer;
  • stage depth through identity operations.

In a one-shot setting, a superformer must contain many candidates and give each candidate a meaningful inherited evaluation. This is already hard for CNNs. It becomes more fragile for ViTs because changing token embedding dimension changes the FC projections used by attention and MLP blocks.

The paper uses two search spaces:

Table 1. Twins-based ViTAS space. It searches patch size/head choices, attention dimensions, MLP dimensions, and depth through TBS layers.

The Channel Fairness Problem

The core figure compares three ways to share channels when searching width.

Figure 1. Ordinal sharing over-trains early channels. Bilateral sharing reduces part of the imbalance but doubles the cost. Cyclic sharing aims to balance training time and channel influence with single-pass cost.

In ordinal sharing, a candidate of width uses the first channels:

If the maximum width is , channel 1 appears in every sampled width, while channel appears only when the widest candidate is sampled. The paper writes the training count for channel as C_A(i) = l - i + 1. That is the bias.

This is dangerous in a supernet:

  • narrow candidates inherit heavily trained early channels;
  • wide candidates inherit a mix of heavily trained and under-trained channels;
  • the search algorithm may confuse weight quality with architecture quality.

BCNet-style bilateral sharing improves the picture by training from both sides, but it needs double training cost and still does not fully equalize the influence of each channel. ViTAS proposes cyclic sharing as a single-pass mapping.

Cyclic Weight Sharing

ViTAS designs an indicator matrix for channel use. In plain notation:

The mapping is chosen under two goals.

Goal Meaning
Training fairness Each channel should be selected about the same number of times.
Influence uniformity Each channel should contribute similar total gradient influence across the dimensions that use it.

The second condition is the more interesting one. In an FC layer, a dimension with more input channels distributes gradient contribution across more channels. The paper approximates the influence of a channel in a width- layer as proportional to 1 / j. Therefore, equal training count alone is not enough; the method also tries to equalize weighted influence.

The final mapping is solved as a small quadratically constrained quadratic program over the binary assignment matrix. This sounds heavy, but it is not in the training loop. Once the mapping is selected, cyclic sharing is just an index mapping for channel slices.

The appendix visualizes cyclic maps for different group counts:

Figure 10. Cyclic channel maps for group counts from 5 to 10. Red channels rotate across layer-width choices rather than staying fixed at the left side.

This matters because ViTAS is not trying to search from a randomly initialized subnetwork each time. It relies on inherited weights. Any systematic imbalance in inherited weights directly biases the search.

Private Class Token

Pure ViT and DeiT-style models use a class token. If patch size is searched, the number of patch tokens changes, and the class token interacts with different token layouts.

ViTAS uses a private class token per patch-size setting.

Figure 2. Different patch sizes get private class tokens, avoiding interference between paths with different token counts.

The point is small but practical. The class token has very few parameters, so privatizing it barely changes memory or compute. But it avoids forcing architectures with different token grids to share one class-token parameter.

Identity Shifting

Depth search is implemented with identity operations. A layer can be a real operation or an identity, so the effective depth changes.

The problem is that the same final architecture can be represented by multiple paths through the superformer. If identity operations are allowed anywhere, several path layouts can collapse to the same sequence of real operations. Those paths may train differently, which makes architecture evaluation noisy.

Figure 3. The original search space can map several superformer paths to the same architecture. ViTAS shifts identity operations deeper so each architecture has a cleaner path representation.

ViTAS resolves this by arranging identity choices at deeper layers inside a stage. With three operation choices and twelve searched layers, the paper says this reduces the operation search space from 3^12 path layouts to 2^13 - 1 effective choices.

The important part is not the exact count. The useful idea is that depth search should avoid many-to-one path encodings. Otherwise the superformer is asked to rank paths even when the final architecture is identical.

Superformer Training Recipe

The authors found that a strong augmentation and regularization recipe can destabilize superformer training. That is slightly counterintuitive because strong recipes are usually helpful for final ViT training.

For search, the superformer is not the final model. It is a ranking proxy. The paper therefore uses a weak recipe:

Table 4. Weakening augmentation and regularization improves the searched/retrained model. The best searched Twins 1.4G model reaches 79.4% after retraining.

The selected superformer search recipe is simple:

Item Setting
Epochs 300
Batch size 1024
Optimizer AdamW
Learning rate 0.001
LR decay cosine
Warmup 5 epochs

The appendix clarifies that superformers for DeiT- and Twins-based spaces use the same search recipe. The final searched architectures are then retrained with the corresponding DeiT or Twins recipe.

This separation is important:

  • superformer training should make ranking stable;
  • final retraining should make the chosen architecture strong.

Treating those as the same objective can make the search proxy worse.

Training Stability Evidence

The loss curves are one of the most useful figures in the paper.

Figure 4. Cyclic sharing is slower in the first few epochs but reaches lower superformer loss later. Identity shifting also converges to a lower loss than the original path encoding.

The paper’s interpretation:

  • ordinal sharing can look better early because a subset of channels gets trained heavily;
  • after enough epochs, that imbalance hurts the superformer as a whole;
  • cyclic sharing trains more evenly and ends with lower loss;
  • identity shifting removes redundant path encodings and also improves convergence.

The text reports final training losses around 2.4 for the original identity setting and 1.5 with identity shifting on ImageNet-100. It also reports that searched architectures from the shifted setting reach 90.4%, compared with 88.3% from the original setting in that experiment.

The ranking-correlation experiment is even closer to the NAS objective.

Figure 5. Cyclic sharing gives higher Pearson, Spearman, and Kendall correlation over sampled paths than ordinal or bilateral sharing.

This is the evidence I care about most. A superformer can have a nice validation loss and still rank candidates poorly. ViTAS explicitly checks correlation over 2000 sampled paths across FLOPs groups, which directly tests whether inherited evaluation is a better search signal.

ImageNet Results: Twins Space

ViTAS first searches in a Twins-based hierarchical transformer space.

Table 3. Searched Twins-based ViTAS models on ImageNet-1k under different FLOPs budgets.

Key rows:

Model FLOPs Params Top-1
Twins-T reimplementation 1.4G 11.5M 77.8%
ViTAS-Twins-T 1.4G 13.8M 79.4%
Twins-SVT-S reimplementation 2.9G 24.0M 81.6%
ViTAS-Twins-S 3.0G 30.5M 82.0%
Twins-SVT-B reimplementation 8.6G 56.0M 83.2%
ViTAS-Twins-B 8.8G 66.0M 83.5%
ViTAS-Twins-L 16.1G 124.8M 84.0%

The tiny result is the cleanest gain: ViTAS-Twins-T improves the reimplemented Twins-T by 1.6 percentage points at roughly the same FLOPs. At larger scales the gains are smaller but still positive.

There is a tradeoff: ViTAS-Twins models often use more parameters and lower throughput than the nearest baseline. The paper reports FLOPs, parameters, and throughput together, which is good. The result should not be read as “searched is always faster.” It is more accurate to say that ViTAS finds stronger accuracy/compute points inside the chosen transformer space.

Ablation: What Actually Matters

The compact ablation table is the best summary of ViTAS as a method.

Table 9. Cyclic sharing improves over ordinal and bilateral sharing, and weak augmentation adds another large gain.

The table can be read in two blocks.

Without weak augmentation:

Sharing Top-1
Ordinal 77.2%
Bilateral 77.6%
Cyclic 77.9%

With weak augmentation:

Sharing Top-1
Ordinal + weak aug 78.1%
Bilateral + weak aug 78.5%
Cyclic + weak aug 79.4%

This says two things:

  1. cyclic sharing is better than the two channel-sharing baselines under the same augmentation regime;
  2. the superformer training recipe is not a side detail, because weak augmentation contributes a large part of the final gain.

So I would not summarize ViTAS as only “cyclic weight sharing.” The method is a package: cyclic sharing, identity shifting, private class token for DeiT-style patch search, and a search-specific weak training recipe.

Comparison With AutoFormer

AutoFormer and ViTAS are close in time and motivation. Both are one-shot NAS methods for Vision Transformers. The difference is where they focus:

Paper Main issue Mechanism
AutoFormer Make inherited subnet evaluation reliable in a ViT supernet weight entanglement
ViTAS Make dimension/channel sharing fair in a ViT superformer cyclic channel sharing

The appendix compares the searched DeiT-T style architectures.

Figure 8. ViTAS and AutoFormer choose different DeiT-T width/head patterns. ViTAS keeps smaller dimensions in early layers and allocates more dimension/head budget later.

The authors point out several patterns:

  • ViTAS keeps smaller dimensions in earlier layers and more dimensions later.
  • Early layers tend to use smaller attention dimensions than MLP output dimensions.
  • Attention dimensions become larger in later layers.
  • ViTAS uses fewer blocks under the tight 1.4G budget, while AutoFormer stays closer to DeiT-T’s layer count.

This is not a universal design law, but it is a useful search result. Under a tight compute budget, the method prefers to save early-layer width and spend more capacity in later attention/head choices.

Searched Architecture Visualization

The appendix visualizes searched Twins architectures.

Figure 11. Visualization of searched ViTAS-Twins architectures and dimension percentages.

The figure is dense, but it gives an intuition for why NAS can still be useful even after strong manual ViT designs. The searched models do not simply scale every stage uniformly. They vary local/global choices, depth, and layer dimensions stage by stage.

The paper’s appendix makes three practical observations from the searched architectures:

  • in the last stage, local blocks can behave similarly to global blocks because the feature size is already small;
  • dimension changes are more obvious in Twins-based architectures than in DeiT-based architectures;
  • MLP and attention dimensions are not uniformly scaled together.

Again, these are clues, not laws. But they are the kind of clues that make a NAS paper more useful than just a leaderboard entry.

Implementation Notes

If I were reproducing ViTAS, I would validate the proxy before trusting the final searched model.

  1. Implement the search space and make sure every sampled path has valid head/dimension divisibility.
  2. Build ordinal sharing first as a baseline; measure whether early channels receive more updates.
  3. Add cyclic channel mapping and verify training-count fairness across channel groups.
  4. Approximate influence balance for FC layers; check that cyclic reduces the channel influence gap.
  5. Add identity shifting for depth search; confirm that multiple superformer paths no longer collapse to the same final architecture.
  6. For DeiT-style patch-size search, keep private class tokens per patch size.
  7. Train a small superformer and compare inherited ranking against a small set of retrained candidates.
  8. Only then scale to ImageNet and evolutionary search.

The paper uses evolutionary search under FLOPs constraints after superformer training. The appendix says it partitions dimensions into 10 groups, samples 50 architectures per budget range, and trains/retrains according to the reported recipes. The search details matter less than the estimator quality: if inherited accuracy is biased, a better evolutionary solver will still optimize the wrong signal.

Limitations

ViTAS is a strong paper, but the boundaries are clear.

  • The search space is still manually designed around DeiT and Twins. It does not discover entirely new attention operators or macro backbones.
  • Cyclic sharing is designed for dimension search. It does not automatically solve every kind of operation-sharing bias.
  • The influence calculation is a useful approximation for FC-heavy layers, not a full theory of supernet training dynamics.
  • The compute budget is substantial: superformer training uses 300 ImageNet epochs, and the final architectures are retrained.
  • Final results depend on the retraining recipe. The paper is careful to reimplement baselines under its recipe, but recipe sensitivity is always a concern in ViT comparisons.
  • Throughput is not always better. Several ViTAS models trade more parameters or lower image/s for higher accuracy.

Takeaway

ViTAS is worth remembering for one sentence:

In Transformer NAS, inherited accuracy is only useful if the superformer trains dimensions fairly.

The paper’s main contribution is not just a searched ViT model. It is the argument that ordinal channel sharing makes the superformer itself biased, and that cyclic channel sharing gives a more reliable ranking signal for token embedding dimensions.

The strongest evidence is the combination of:

  • Figure 1, which makes the channel imbalance visible;
  • Figure 5, which tests ranking correlation directly;
  • Table 9, which isolates cyclic sharing and weak augmentation;
  • ImageNet results in both Twins and DeiT spaces;
  • COCO/ADE transfer results showing the searched backbones are not ImageNet-only artifacts.

That makes ViTAS a useful bridge between AutoFormer and later ViT search-space work such as S3. AutoFormer makes weight sharing more structured; ViTAS makes dimension sharing fairer; S3 later asks how to evolve the search space itself. All three are really about the same hidden problem: the supernet is the measurement instrument, and if the instrument is biased, NAS optimizes noise.

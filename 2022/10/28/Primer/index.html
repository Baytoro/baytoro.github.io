So D R, Mańke W, Liu H, Dai Z, Shazeer N, Le Q V. Primer: Searching for Efficient Transformers for Language Modeling.

Paper

Primer is an AutoML paper for Transformer language models. Unlike many NAS papers that search high-level macro-architectures, Primer searches over primitive operations inside Transformer blocks. The result is not a completely new model family, but a set of small changes that transfer well.

Search Space

Primer uses a program-like search space. Candidate programs specify block-level transformations around attention and feed-forward sublayers.

The figure shows the search-over-programs setup. Candidate programs are composed from primitives and evaluated under a fixed budget.

What The Search Found

Two notable changes are:

Squared ReLU

Instead of ordinary ReLU, Primer uses:

This is a simple activation change, but it later appeared in several efficient Transformer and LLM designs.

Depthwise Convolution After Attention Projections

Primer also adds depthwise convolution around attention projections. This injects local mixing into the Transformer block without replacing attention.

Why This Matters

The discovered changes are local and interpretable. They can be inserted into existing Transformer recipes and ablated directly. That makes them more useful than a complicated searched architecture that is hard to analyze.

Search As Idea Generation

Primer is a good example of AutoML as architecture idea generation. The search process finds candidate primitives, and humans then test whether those primitives transfer to larger models.

The key question is transferability. A primitive found on a proxy task is only valuable if it remains useful at larger scale.

Takeaway

Primer’s most important output is not the search algorithm itself. It is the evidence that primitive-level search can discover simple Transformer block changes that human designers can reuse.

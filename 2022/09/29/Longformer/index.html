Paper

Longformer 是长文档 NLP 中非常实用的一条路线。它不追求每个 token 都全局互看，而是把 attention pattern 改成局部窗口 + 少量全局 token，从而让复杂度从 变成接近 。

Attention Pattern

局部窗口 attention 让每个 token 只看左右 个 token：

这足够捕捉大多数局部语言结构。对于 QA、分类等任务，再给 [CLS]、question token 或 task-specific token 全局 attention，让它们可以读写整篇文档。

Engineering Note

图中 full self-attention 的 time/memory 随序列长度爆炸，而 Longformer 的 CUDA/chunk 实现基本线性增长。这里的重点是 attention pattern 和 kernel 实现都要配合：稀疏 pattern 如果实现成低效 gather/scatter，也不一定真的快。

Takeaway

Longformer 的思路很朴素但有效：长文档不一定需要每个 token 对每个 token 全连接。局部窗口负责文本流，全局 token 负责任务汇聚。它适合文档分类、长上下文 QA、长摘要前处理等任务，但对需要任意远 token 精确交互的场景会受 pattern 限制。

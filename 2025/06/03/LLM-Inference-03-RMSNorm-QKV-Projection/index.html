This post connects two operations that sit right before attention in a Llama-style block: RMSNorm and Q/K/V projection. RMSNorm keeps the hidden vector scale controlled. QKV projection then creates the three views that attention needs.

For now this is ordinary multi-head attention. GQA will change the K/V side later.

RMSNorm

RMSNorm normalizes each token vector along the hidden dimension. For one vector x with shape [D]:

The shape does not change:

Tensor Shape
x [B, T, D]
rms [B, T, 1]
weight [D]
y [B, T, D]

The implementation in the teaching repo is intentionally small:

The small detail I always check is keepdim=True. Without it, rms would be [B, T], and the broadcast against [B, T, D] would no longer express the operation clearly.

Common Pitfalls

The first pitfall is forgetting the divisibility condition:

The second pitfall is assuming q/k/v share parameters because they share shape. They do not. They are three separate learned projections.

The third pitfall is thinking RMSNorm changes representation width. It changes scale, not shape. It is a local operation over the hidden dimension.

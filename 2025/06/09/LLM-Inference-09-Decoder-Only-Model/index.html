Common Pitfalls

First, do not share one cache across layers. The keys and values are produced by layer-specific projections.

Second, final RMSNorm happens after the last block and before the LM Head.

Third, use_cache=False should return no cache and should not accidentally append side state.

Fourth, the model forward still returns logits for every position in the current call. During decode that current call has T = 1, so logits are [B, 1, V].

The attention path gets most of the attention, but the block is not only attention. A Llama-like block alternates normalized attention and normalized MLP, with residual connections around both.

Goal

The block-level dataflow is:

flowchart LR
    x0["x
[B,T,D]"] --> n1["RMSNorm"]
    n1 --> attn["GQA attention
[B,T,D]"]
    attn --> add1["residual add"]
    x0 --> add1
    add1 --> x1["x
[B,T,D]"]
    x1 --> n2["RMSNorm"]
    n2 --> mlp["SwiGLU MLP
[B,T,D]"]
    mlp --> add2["residual add"]
    x1 --> add2
    add2 --> out["block output
[B,T,D]"]

The block preserves shape. It changes the content of the hidden states, not their width or sequence length.

SwiGLU MLP

The MLP is position-wise. It applies the same feed-forward network to each token independently:

Mathematically:

Shape trace:

Step Shape
x [B, T, D]
gate_proj(x) [B, T, F]
up_proj(x) [B, T, F]
silu(gate) * up [B, T, F]
down_proj(hidden) [B, T, D]

The MLP does not mix tokens. Token mixing happened in attention. The MLP transforms each token’s channel representation.

The residual adds require exactly matching shapes. That is a useful sanity check: if attention or MLP returns anything other than [B, T, D], the block cannot add it back.

Shape Trace

Step Tensor Shape
input x [B, T, D]
attention norm attn_in [B, T, D]
attention attn_out [B, T, D]
first residual x + attn_out [B, T, D]
MLP norm mlp_in [B, T, D]
SwiGLU MLP mlp_out [B, T, D]
second residual x + mlp_out [B, T, D]

The cache is side state from the attention branch. It does not change the hidden-state shape.

Minimal PyTorch

Common Pitfalls

First, do not put the residual around the normalized input. The residual adds the branch output back to the branch input.

Second, MLP hidden dimension F is not vocabulary size V. It is an internal expansion width.

Third, the block has two RMSNorm layers. One feeds attention; the other feeds MLP.

Fourth, the cache belongs to attention, but the block is responsible for returning it so the full decoder can keep one cache per layer.
